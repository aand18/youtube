## Objective
- Write a Node.js script at `/home/dev/youtube/test_ump.js` that tests whether YouTube's UMP server returns audio streams for combined vs standalone requests, using video ID `dQw4w9WgXcQ`.

## Important Details
- No external npm packages — only Node.js built-in modules.
- YouTube's SABR endpoint (`serverAbrStreamingUrl`) consistently returns **HTTP 403** for all external POST requests, regardless of:
  - Protobuf encoding (tried both old `VideoPlaybackRequest` and correct `VideoPlaybackAbrRequest` from googlevideo)
  - Cookies from page request
  - Extra headers (Sec-Fetch-*, TE: trailers, etc.)
  - Empty body vs valid protobuf body
  - GET vs POST
  - With/without `rn`, `cpn`, `alr` params
  - HTTP/2 (Node.js http2 module gives protocol error)
- The 403 is a **server-side restriction** — the endpoint requires browser context (TLS fingerprint, session tokens, HTTP/2 trailers, etc.) that cannot be replicated from Node.js.
- From PipePipeExtractor #66: successful SABR requires a real browser session and eventually a PO token for protected content (`status=3` wall).
